# BUYWISE AI — ADMIN CONTROL CENTER SPECIFICATION

## Overview
The BuyWise AI Admin Control Center operates as a production-grade operations dashboard for managing e-commerce catalog imports, user submission moderation, competition lifecycles, notification dispatches, and security audit logs.

## Core Operations Grid (18 Action Buttons)
1. `+ CREATE COMPETITION`: Launch and schedule weekly fashion challenges.
2. `+ ADD COMPETITION PRODUCT`: Attach verified merchant product to active competition.
3. `📦 PRODUCT MANAGER`: View, edit, and assign Try-On eligibility to catalog items.
4. `👤 REVIEW SUBMISSIONS`: Moderation queue for user competition entries with privacy isolation.
5. `🗳 VOTING MANAGEMENT`: Freeze votes, run server-side fraud checks, and inspect vote metrics.
6. `🏆 DECLARE WINNER`: Trigger server-verified winner declaration algorithm.
7. `⭐ FEATURE WINNER`: Publish winning entry to Home Screen Spotlight.
8. `+ ADD PRODUCT`: Import live product by URL (Amazon, Flipkart, Myntra, Meesho).
9. `👥 MANAGE USERS`: Inspect user accounts and role assignments.
10. `🏪 MANAGE PARTNERS`: Direct portal for merchant onboarding & order fulfillment.
11. `🛒 MANAGE ORDERS`: Order tracking and logistics status.
12. `🎟 MANAGE COUPONS`: Coupon Truth Engine admin control.
13. `📢 SEND NOTIFICATION`: Dispatch FCM & Web Push notifications on Asia/Kolkata timezone.
14. `📚 KNOWLEDGE HUB`: Editorial blog & consumer guide CMS publisher.
15. `🎯 AD MANAGEMENT`: Ad placements and affiliate banner controls.
16. `✨ VTO MANAGEMENT`: VTO engine parameters, budget governor caps, and emergency stops.
17. `🔐 SECURITY LOGS`: Audit trail of all administrative events.
18. `⚙ APP SETTINGS`: Global app configuration flags and rate limits.
